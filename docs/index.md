# Knob Workshop

Build firmware for the Guition JC3636K518C round knob display with the AI coding tool you
already use. This site holds the workshop material; the plugin itself lives in the
[repository](https://github.com/dalager/knob-workshop).

## Before the workshop

1. Install Docker and pull the toolchain: `docker pull espressif/idf:release-v5.3`
2. `pip install esptool`
3. Bring a USB-C data cable and your AI coding tool of choice.
4. Install the plugin: see the [install card](install-card.md).
